QUICK GUIDE

How File Organizer AI works

  1. Select a folder. Choose a folder using the browser's permission dialog.
  2. Preview your files. The app reads file names, sizes, extensions and modified dates.
  3. Review the plan. Smart organize groups files into category folders.
  4. Confirm changes. Nothing is moved without your confirmation.

Browser support varies. Use recent Chrome or Edge on localhost or HTTPS. The browser may use an online speech-recognition service; microphone permission is required. Files are searched only in folders you explicitly select. A website cannot reliably launch arbitrary local files in Windows desktop apps: Open previews supported formats in a browser tab or downloads the file. Use a desktop app for guaranteed Windows default-app launching.
